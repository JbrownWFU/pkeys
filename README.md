# Pkeys

A simple Go CLI tool for AES-256 GCM encryption.

## Installation

To install this project, you need to have Go installed on your system. After that, use the following command:

```shell
go get github.com/JbrownWFU/pkeys
```

This will download and compile the project.

## Usage

The project provides several commands for encryption and decryption purposes:

- **Generate Key**: Generate a new 32-byte (256-bit) AES encryption key. Run:
  
  ```shell
  pkeys generate
  ```
  
- **Encrypt Text**: Encrypt a plaintext string or the clipboard contents. If no plaintext is provided, the system clipboard will be used and overwritten with ciphertext. Run:

  ```shell
  pkeys encrypt
  ```

  Or use the shortcut:

  ```shell
  pkeys -e
  ```
  
- **Decrypt Text**: Decrypt a hexadecimal ciphertext string or the clipboard contents. If no ciphertext is provided, the system clipboard will be used and overwritten with plaintext. Run:

  ```shell
  pkeys decrypt
  ```
  
  Or use the shortcut:
  
  ```shell
  pkeys -d
  ```

- **Peek Key**: Peek and print the last 4 characters of the current environment key `PKEYS_PASS`. Run:

  ```shell
  pkeys peek
  ```
  
## Configuration

The project uses the environment variable `PKEYS_PASS` to store the AES encryption key. You can set it by running:

```shell
export PKEYS_PASS=<your_key>
```

Replace `<your_key>` with your actual encryption key.
